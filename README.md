# ГРАНЕЛЬ — карта объектов

Отдельное приложение в прежнем формате: Streamlit + Python + objects.xlsx.
Распакуйте архив в новую папку. Старый сайт «Линкор» и его objects.xlsx заменять не нужно.

## Запуск на Windows

Установите Python 3.11 или 3.12. Откройте терминал в папке приложения:

```console
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Либо запустите START_WINDOWS.bat (после установки зависимостей).

## Ключ 2ГИС

1. Откройте https://platform.2gis.ru/ и создайте API-ключ в своей подписке.
2. Нужны сервисы Raster Tiles API (карта), Geocoder API (поиск домов), Routing API (маршруты). Для общественного транспорта нужен доступ к соответствующему сервису. Наличие ключа само по себе не означает доступ ко всем API.
3. Скопируйте `.streamlit/secrets.toml.example` в `.streamlit/secrets.toml` и замените значение:

```toml
DGIS_API_KEY = "ВАШ_НОВЫЙ_КЛЮЧ"
```

4. Перезапустите приложение. Для разового запуска можно вставить ключ в поле боковой панели. Файл secrets.toml не загружайте в публичный репозиторий.
5. Для Streamlit Cloud задайте DGIS_API_KEY в настройках Secrets приложения. Сначала проверьте новый ключ, затем отключите старый в кабинете 2ГИС, если он больше нигде не нужен.

Документация:
- https://docs.2gis.com/platform-manager/subscription/keys
- https://docs.2gis.com/maps/others/rastertiles/overview
- https://docs.2gis.com/en/api/search/geocoder/overview

Ключ растровой карты используется браузером для загрузки тайлов. Настройте доступные ограничения ключа в кабинете 2ГИС. Ключ не записывается в Excel или архив.

## Первое нанесение домов

В исходных документах координат нет. Они намеренно не подменены случайными точками или центрами ЖК.
После ввода ключа нажмите «Найти недостающие координаты». Программа запросит 2ГИС по каждому адресу без координат (до 87 адресов при первом запуске). Сверьте найденные адреса в разделе «Реестр домов → Сверка адресов геокодера».

Если найдено несколько зданий или адрес не распознан, программа не выбирает произвольный результат. Уточните адрес либо внесите координаты в Excel. После проверки скачайте coordinates.json и положите рядом с app.py: при следующих запусках повторные запросы не нужны. Координаты, внесённые непосредственно в Excel, имеют приоритет над JSON.

Без ключа доступен реестр и фильтры. Карта и маршруты требуют сети и действующего доступа к API. Координаты хранятся в сессии, пока вы не скачаете JSON. Загрузка Excel через интерфейс также действует в текущей сессии; для постоянного обновления замените objects.xlsx рядом с app.py.

## Что включено

- 87 адресных записей из всех 13 таблиц пользователя.
- Названия ЖК, адреса с городом, даты ввода, этажность, площади, квартиры, НЖП, подъезды, лифты и тарифы.
- Поля «Ответственный», «Телефон», «Статус», «Комментарий» для заполнения в Excel.
- Фильтры по ЖК, ответственному и тексту адреса.
- На общем плане подпись ЖК и число домов в отфильтрованном реестре. На масштабе 13 и крупнее — отдельные дома. Маркеры ЖК вычисляются по уже найденным домам, поэтому полнота карты видна отдельным счётчиком.
- Маршрут А → Б между выбранными домами или введёнными адресами: автомобиль, пешком, общественный транспорт, если это разрешено ключом.
- Карточки со всеми характеристиками и выгрузка текущей выборки в CSV.

## Правила Excel

Первая строка — заголовки, один дом — одна строка. Не удаляйте ID и обязательные столбцы. Сохраняйте уникальность ID. Не добавляйте итоговые строки в список домов. Телефоны храните как текст. Пустое значение означает отсутствие данных, а не ноль.

Исходный адрес сохранён отдельно. Исправлены опечатки «Новоостапоская» и «Теннистый», «44/1» приведено к «44к1». Для маршрутизации добавлены населённые пункты.

В исходнике некоторые итоги не совпадают с суммой строк (например, «Москвичка»). В приложение перенесены строки домов; суммы считаются по ним. Исходные итоги можно проверить в SOURCE.md.
Для Яганова, 7 и 10 этажность записана датами 1900 года — оставлена как текст и помечена для уточнения. Для Эйнштейна, 5 ряд характеристик похож на другую строку исходника: данные сохранены и отмечены. НЖП с составными значениями («16+153м/м» и т. п.) не преобразованы в выдуманное общее число.
Число домов означает количество адресных записей пользователя, а не число секций или все корпуса ЖК.
